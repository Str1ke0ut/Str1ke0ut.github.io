# KAIVAZ personal website

A static, mobile-friendly personal site for KAIVAZ, hosted with GitHub Pages.

## Music
1. Add audio files to `songs/`.
2. Edit `assets/js/songs.js` and ensure each `file` matches the filename exactly (including capitalization and extension).
3. Commit the changes. The player loads the configured playlist.

GitHub Pages is static hosting; browser JavaScript cannot list a server folder automatically. `songs.js` is the playlist manifest.

## Social links
Instagram, YouTube, Facebook, and TikTok links are configured in `index.html`.

## Publish
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Public repository warning: files committed here, including audio, are publicly accessible. Do not commit private or unreleased audio unless you intend it to be public.
