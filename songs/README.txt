KAIVAZ MUSIC FOLDER

Drop your audio files in this folder. Example filenames:
- Messiah.mp3
- No Exit.mp3
- Killing It.mp3

Then make sure assets/js/songs.js lists the exact filename and title.
The website cannot automatically scan this folder on GitHub Pages, so songs.js is the playlist index.

Audio files committed to this PUBLIC repository can be downloaded by anyone. Only add tracks you are comfortable making public.
